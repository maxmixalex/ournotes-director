# 编辑工作区：显卡、时间轴与全屏

## 显卡

打开 **设置 → 图形 → 渲染显卡**，选择由 Windows 决定、节能或高性能。后两项会显示 Windows DXGI 排序中对应的真实设备名；没有可枚举的硬件时只显示策略名，不生成显卡名称。

保存设置会修改当前用户对编辑器 EXE 和导出引擎 EXE 的 GPU 偏好。**重新启动应用后生效**，页面区分尚未保存、本次启动的偏好与等待重启。如果在 Windows 中删除应用覆盖项，设置页会回显自动；保存时同时核对两个实际 EXE 的配置。Windows 图形设置入口用于检查系统覆盖项。

“当前 OpenGL”和“当前呈现”是实际会话读数，不是请求值。OpenGL 与 D3D11 共享纹理仍使用驱动允许的设备配对；共享不可用时显示兼容模式和原因。节能／高性能属于 Windows 的设备选择策略，不是任意多卡系统上的 LUID 强制绑定。双显卡实机的切换与跨驱动行为需要在相应硬件上验证。

实现参考：

- Microsoft `IDXGIFactory6::EnumAdapterByGpuPreference`：https://learn.microsoft.com/windows/win32/api/dxgi1_6/nf-dxgi1_6-idxgifactory6-enumadapterbygpupreference
- NVIDIA 关于 Windows 按应用选择显卡：https://www.nvidia.com/content/Control-Panel-Help/vLatest/en-us/mergedProjects/3D%20Settings/Setting_the_Preferred_Graphics_Processor.htm

## 时间轴

左侧 **行高** 打开 24–108 的纵向缩放滑块，提供紧凑、标准、详细三档预设。也可用 **Ctrl+Shift+滚轮** 调整轨道高度；**Ctrl+滚轮** 仍只调整时间比例。行高按场景／主页工作台分别保存，不写入演出 JSON。

点击角色或场景对象的分组标题，可收起或展开下属轨道；“全部轨道”菜单中可一次展开／收起所有分组。收起时显示占用时间的概览线，原始片段、参数和入出点仍然保留。“显示所选片段”会解除排除它的筛选、展开所属分组，并同时调整横向和纵向滚动。

在标尺或时间轴空白处按住拖动可连续定位。暂停状态仍会绘制中间的真实原生帧，松手定位至最新输入。队列最多保留一个正在执行的定位和一个最新待执行目标；普通鼠标移动不再反复取消正在执行的帧，退出工作台或替换文档时仍会取消。

复杂场景在拖动中按实际绘制成本选择完整、1/2 或 1/4 的场景绘制尺寸，状态栏显示比例。松手、返回工作台或开始播放恢复完整画质；随后的离散播放与导出等待最终定位。同一个来源的新项目也会清除旧入出点、筛选、折叠、手势和局部缩放。

## 节目监视器

单击节目监视器取得焦点后，**F1** 进入全屏；再次 **F1** 或 **Esc** 恢复。检查器、输入框、时间轴和对话框中的 F1 不会触发监视器全屏。

全屏只改变窗口呈现方式、面板可见性和网格范围，不移除或重新挂载原生画布。原先的暂停／播放状态、播放头和渲染会话保留；打开其他工作台或抽屉前自动退出全屏。之前已最大化的面板会在退出后恢复；系统从全屏恢复窗口时也同步恢复编辑器外框。

暂停的 GPU 画面也会随全屏与窗口尺寸调整重新呈现。尺寸请求合并后交给原生渲染线程，不在界面布局事件中等待 GPU，也不为刷新全屏而重新定位演出。

## 独立 Live2D

独立工作台始终选择一个动作和一个表情；更换选项立即替换当前选择，不增加时间轴片段，也不移动播放头。初始预览、参数修改、完整动作画布与导出使用同一个项目。第零帧在显示前完成所选姿态的采样。

从场景打开的角色保留原场景副本、播放位置和区间。旧工作台项目第一次打开时，在其保存位置固定动作和表情；之后拖动播放头不会重新选择源剧情中的其他动作。工作台参数面板只显示实际应用到当前工作台的固定参数。多段动作和表情编排仍在场景工作台完成。

## 原剧情导入

原有语音／演出时间仍由同一个原生解释器实际求值，不能以估算代替。JSON 解析、素材展开和批量转换在后台操作独立文档；导入片段只在完成后统一校验，动作／表情后继和时间轴显示跨度采用批量计算。

读取原剧情时直接展开原生文档并提取角色关联，省去旧关键帧编辑器的静态时间扫描、采样和撤销快照。只为最终可编辑场景创建节目监视器，导入期间保留原画面。

真实时序分析在模型初始化期间就开始解码接下来可能使用的语音，最多四个解码任务、八条前瞻，并复用原有 PCM 缓存。原生解释器仍按原顺序逐帧运行；未执行分支的预取失败只在实际用到声音时报告。提示条的“取消解析”可中止当前导入，结束解码进程并清理其临时输入。编辑、撤销或切换项目后，旧导入结果不会覆盖新的项目。

候选场景的首帧预览成功后，才一起替换当前文档、选择、撤销记录和草稿。在最终预览载入期间仍可取消；取消或载入失败会保留当前项目，并恢复它的预览。

启动日志的 `Story import` 记录展开、快照、原生时间分析、编辑文档转换、时间轴绑定与最终预览各阶段。`EditorPerformanceTests` 与 `CreativeSourceImporterTests` 和旧路径逐项对照，包括同序号、重复执行、结束停留和原始数字 token。Windows 实窗证据中还包含 `story-import.json`。

`story-import.json` 的 `nativeAnalysis` 进一步记录模型／图形初始化、时序运行、资源清理和解码数据量。累计解码时间来自并行工作线程，不能与墙钟耗时直接相加。
